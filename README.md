Static HTML, CSS and JavaScript. 14 topic maps and 63 subtopic routes. Source-backed depth is restored in 49 subtopics; others show preparation states or genuine source gaps. Coverage and limitations are below. The editable source archive also contains BUILD-NOTES.md.

## Run the editable source
Serve this folder with a static web server. Its modules, fonts, emoji and topic JSON are local assets. The deployed version is bundled into a self-contained index, plus manifest, service worker and icons.

## Features
- Editable device-only Train journey ticket, not a valid travel ticket.
- Device-only Packing and Bedroom checks.
- Verified external resource links instead of rebuilt third-party services.
- Typed-area Maps searches, without GPS.
- Quiet optional sounds and saved preference.
- Offscreen/background motion pause and reduced-motion support.
- PWA manifest and network-first offline fallback after a successful online visit.

No member directory, private profiles, booking, payment, licence applications or music-account connections. Source gaps and held claims still need review. Physical Android installation has not been tested.

## Built
14 topic maps and 63 subtopic routes in a static HTML/CSS/JavaScript PWA.
Source depth is restored in Train, Things to Carry, Cab, Bus, Stay, Itinerary, Flight, all five Home pages, all four Watch/Read/Listen pages, Hobbies, Swimming, Driving, all four Career pages, Moving to A New City, Mobile, Parents, Kids, Cats, Dogs, all seven Health pages, all five Wealth pages, Places, both Fashion pages and Legal Basic, Buying Home, Buying a Car, Marriage and Pregnancy (49 subtopics). Problem Solving, TV, Earphones and Power Bank were empty in the original and are labeled as gaps. Seven People sources contained only a title and are also labeled as gaps.

Train has an editable, on-device-only journey ticket. It is not a valid travel ticket. Packing and Bedroom checks save on the device. Location searches use a typed area, not GPS. News has a copyable prompt and is not a live news feed. No bookings, purchases, account connections, private profiles or member data are built into this app.

Fonts, scene drawings and emoji illustrations are bundled into the deployed app. Sounds are subtle and optional; the preference saves on the device. Motion respects reduced motion and pauses offscreen or in background tabs.
